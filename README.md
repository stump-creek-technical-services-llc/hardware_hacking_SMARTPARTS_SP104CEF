# SMARTPARTS SP104CEF

* [Manufacturer ref](https://www.adorama.com/isp104cef.html)
* [Source]()

> The Smartparts SP104CEF 10.4" Digital Picture Frame combines classic styling and modern convenience. Pictures are sharp and vibrant thanks to the 640x480 pixel LCD panel. Photos can be viewed in an automatic slide show or one at a time with the use of the built-in control buttons or the supplied remote control.
>
> Slideshows can be enhanced with the music. Video clips can be shown as well. Updating the internal memory is easy with the help of the included OptiPix Pro software for Windows. In three easy steps, OptiPix helps you display photos, Power Point slides and PDF files on the frame.
